# Одолей вирус

**Неоновая браузерная игра с видом сверху.**

🎮 **[Открыть игру на GitHub Pages](https://vickar2000-crypto.github.io/-/)**

> Если страница ещё не открывается, дождитесь завершения публикации GitHub Pages.

## Управление
- **WASD** — движение.
- **Q** — выстрел в направлении последнего движения.
- **P / Esc** — пауза.
- Усиления и выходы активируются касанием.
- На мобильных устройствах доступны экранные кнопки.

## Особенности
- Три случайно генерируемых лабиринта с возрастающей сложностью.
- Пять вредных бактерий на каждом лабиринтном уровне.
- Усиление на каждом уровне увеличивает урон.
- Три жизни.
- Урон от касания врагов, попадания вражеских снарядов и опасных зон.
- Финальная арена с вирусом-боссом, шкалой здоровья и отскакивающими вирусными частицами.
- Синтезируемая фоновая музыка и звуковые эффекты, отключаемые кнопкой.
- Главное меню, пауза и подтверждение выхода.

## Запуск локально
Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны.
